How the translator is doing

Practice with speaker-verified Kitaita

Sentence levels L2–L4 (noun+adjective, subject–verb, subject–verb–object) need a sentence-structure tag the translator API does not provide yet; sentences are grouped together for now.

Kitaita Scrabble

Words are checked by the marker-oracle: nouns by dictionary, verbs and adjectives by Kitaita grammar rules, so any verb root takes any allowed prefixes. Parts that rely on unverified data are underlined.

Tiles and how they are scored

Rarer letters score more: score = clip(round(k · ln(fmax/f)), 1, 10), using how many different words contain each letter. Single-letter tiles (gh = g + h); apostrophes are ignored.
